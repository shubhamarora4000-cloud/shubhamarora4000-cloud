# 🌟 How to Highlight Your 3D Profile on Your GitHub Main Page

GitHub has a feature called **Profile README**. When you create a public repository with the exact same name as your GitHub username, GitHub renders its `README.md` right on the main page of your profile (`https://github.com/shubhamarora4000-cloud`)!

Here is how to set it up in 2 minutes:

---

### Step 1: Create Your Profile Repository on GitHub
1. Open your browser and go to: **[https://github.com/new](https://github.com/new)**
2. In the **Repository name** field, type: `shubhamarora4000-cloud`
   > *GitHub will display a green banner saying: "✨ You found a secret! shubhamarora4000-cloud is a special repository that you can use to add a README.md to your GitHub profile."*
3. Make sure the repository is marked as **Public**.
4. Check **"Add a README file"**.
5. Click **Create repository**.

---

### Step 2: Push the 3D Profile Files
Clone your new profile repository or simply copy the files from this folder:

```bash
# Clone your special profile repository
git clone https://github.com/shubhamarora4000-cloud/shubhamarora4000-cloud.git
cd shubhamarora4000-cloud

# Copy the README.md and the .github folder from github-profile-3d/ into it
# (or drag and drop them on the GitHub web UI)

git add .
git commit -m "feat: setup 3d isometric github profile and showcase"
git push origin main
```

---

### Step 3: Enable the 3D Contribution Graph Workflow
1. In your `shubhamarora4000-cloud` repository, click the **Actions** tab.
2. Select **GitHub-Profile-3D-Contrib** from the left sidebar.
3. Click **Run workflow** -> **Run workflow**.
4. Within 60 seconds, it will generate the 3D isometric contribution graph SVG and display it on your main profile page!

---

### Step 4: Pin `terraform-azure-labs` to Your Main Profile
1. Go to your GitHub profile page: **[https://github.com/shubhamarora4000-cloud](https://github.com/shubhamarora4000-cloud)**
2. Scroll to the **Pinned** section.
3. Click **"Customize your pins"**.
4. Check **`terraform-azure-labs`** and click **Save pins**.

🎉 Your GitHub main profile will now feature your **3D isometric cloud architecture**, **3D contribution graphs**, and **production enterprise landing zone**!
